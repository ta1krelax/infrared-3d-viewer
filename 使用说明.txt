红外温度 3D 浸泡示意图 v1.10
================================

运行环境
--------
Windows 10/11 64 位，无需安装 Python。

使用方法
--------
1. 双击 Infrared3DViewer_v1.10.exe。
2. 点击“读取 TXT / TIFF”，选择一个红外温度文件。
3. 设置中央 1/3 截取、浸泡比例和水下红外吸收比例。
4. 按住鼠标左键拖动旋转，使用滚轮缩放。
5. 点击“导出 PNG / TIFF”保存当前视角。

也可以将 TXT/TIFF 文件直接拖到 EXE 上打开。

数据格式
--------
推荐一个 TXT 对应一个温度帧。支持：

1. 二维温度矩阵，数值可用空格、逗号、分号或 Tab 分隔。
2. X、Y、temperature 三列的完整规则网格。
3. 8-bit、16-bit 整数/浮点以及 32-bit 浮点 TIFF；读取时保留原数值。

默认单像素尺寸为 0.01 mm，默认保留 X/Y 中央 1/3 区域。

材质与渐变
----------
水上样品、水下样品和玻璃水体均可分别调整颜色、亮度与不透明度。
“显示样品网格”可控制网格开关和线数；“显示玻璃体轮廓高光”可控制水体边缘。
顶部白化渐变会按原始数据值由基础颜色过渡到白色；白化强度和 γ 曲线均可调整。
水体的 X/Y 外轮廓与固体完全一致，不会向固体之外延伸；水上凸起处会自动开孔。
水体顶面、四周侧壁、样品及网格使用同一个逐面片深度排序场景。完全藏在样品下方的
水平水底面不会创建，避免它在正面俯仰视角下错误覆盖露出水面的固体。水上样品设为
100% 不透明时，会正确遮住后方的水体、样品和网格；半透明水体仍可显示水下样品。
水体各面使用相同的颜色、亮度和不透明度，截断边缘不会再额外变亮。
固体裁切侧壁默认关闭，因此边缘截断的峰值不会产生遮挡其他区域的灰色竖直面。
如确实需要实体截面，可手动开启“显示固体侧壁（裁切面）”。

水面边界细化
------------
点击一次“细化一次”，会在原始数据副本的每一对相邻点之间插入新点：
若两个点分别位于水上和水下，新点精确等于水面阈值；否则新点为两者平均值。
连续点击会逐级增加网格密度；修改浸泡比例后会从原始副本按新水面重新计算。
为避免内存和拖动性能问题，细化后的安全上限为 90,000 个网格点。

整体比例
--------
X、Y、Z 显示比例可以独立调整，只改变画面比例，不改变温度、吸收或物理尺寸计算。
“扁平长方体预设”会设置 X=3、Y=1、Z=0.12；“重置整体比例”恢复为 1:1:1。

视角预设
--------
下拉菜单提供原有透视预设，以及正交正视、后视、左视、右视、俯视、等轴测和反向
等轴测；投影模式也可以单独选择“透视投影”或“正交投影”。
视角统一使用样品 X/Y/Z 旋转角及缩放百分比：0°/0°/0° 为正视，X 为俯仰，Y 为
水平旋转，Z 为画面滚转。预设会回填数字；左键拖动和滚轮缩放也会把最终数值同步回
GUI，方便使用同一组参数定量复现视角并导出。

透明背景导出
------------
“导出透明背景（PNG / TIFF）”默认开启。导出的 PNG/TIFF 为带 Alpha 通道的 RGBA 图像，
画布背景完全透明，样品、水体及其半透明效果会保留。取消勾选可恢复原来的浅色背景。
“同时导出当前裁剪范围的源数据副本”默认开启。图像旁会生成名称带
`_cropped_source` 的当前裁剪数据；已有同名文件时自动添加序号，不会覆盖旧文件。

性能说明
--------
当前版本使用兼容性更高的 Matplotlib/TkAgg CPU 渲染，并自动将预览等距降采样到最多
160 × 160 点。该渲染器不能直接切换显卡；如超大 TIFF 在拖动时仍卡顿，需要另行使用
PyVista/VTK 构建 GPU 版本，安装包体积会明显增大。

浸泡模型
--------
水面温度 = Tmin + 浸泡比例 × (Tmax - Tmin)
水下显示高度 = 水面温度 + (原温度 - 水面温度) × (1 - 吸收比例)

提示
----
单文件程序首次启动时需要解压运行组件，可能稍等几秒。
若 Windows SmartScreen 提示“Windows 已保护你的电脑”，这是未购买代码签名证书导致的；
确认文件来源后，可点击“更多信息”→“仍要运行”。
